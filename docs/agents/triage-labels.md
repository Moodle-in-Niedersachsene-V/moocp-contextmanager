# Triage-Labels

`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix` (1:1-Vokabular wie in den Schwesterprojekten). Erledigte Issues werden nach Rückfrage mit `gh issue close <nr> --comment "..."` geschlossen.

Art: `bug`, `enhancement`, `refactoring`, `documentation`, `question`. Alle Labels, Issues und Pull Requests sind englisch.

Abgelehnte Erweiterungen stehen in `.out-of-scope/`, eine Datei je Thema; vor der Triage lesen. Der Ordner entsteht mit der ersten Ablehnung.

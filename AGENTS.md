# moocp-contextmanager

Plugin für moocp, das der KI einen Kontextbereich in einem lokalen Ordner oder auf einem WebDAV-Server bereitstellt (Dart, MCP-Server auf `127.0.0.1`).

## Immer relevant

- Kanonische Regeln: [CLAUDE.md](CLAUDE.md). Sie gilt für jedes KI-Werkzeug, auch für Codex.
- Entscheidungen mit Begründung: [docs/adr/](docs/adr/); Fachsprache: [GLOSSARY.md](GLOSSARY.md).
- Vor jedem Edit die Datei lesen. Bei Funktionsänderungen die Aufrufer suchen.
